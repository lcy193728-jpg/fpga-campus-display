# 字幕控制与TF卡素材管理上位机

本目录是最终交付版配套上位机，包含迎新/应急流动通知控制和TF卡图片、
迎新音乐制作功能。扩展全部位于PC端，不修改FPGA位流，也不增加板端资源。

## 启动

1. 安装 Python 3。
2. 首次使用时执行：`pip install pyserial pillow`。
3. 用 USB 连接开发板板载 CH340 串口。
4. 双击 `启动迎新串口上位机.bat`。
5. “字幕与滚动通知”页用于修改迎新、应急场景的底部通知、速度和暂停状态。
6. “TF卡图片与音频”页用于选择FAT32 TF卡、按场景槽位导入图片以及制作迎新音乐。

串口固定为 `115200 / 8N1`。上位机只修改流动字幕，不改变图片、音频、转场、马赛克、告警类型、计时或疏散箭头。配置在帧边界提交，断电后恢复 FPGA 内置默认内容。

## 图片素材管理

- 用户选择场景和槽位即可，上位机自动生成 `WELn.BMP`、`MEETn.BMP`、
  `QUIZn.BMP` 或 `ALMn.BMP`，无需手动命名。
- JPG、PNG、BMP、WebP统一转换为640×480、24bit、BI_RGB、正高度BMP。
- 支持“完整显示（黑边）”和“居中裁剪”两种适配方式。
- 写入采用同卷临时文件替换，完成后重新检查BMP头并核对SHA-256。
- 抢答槽位语义固定：`QUIZ1..3`为题目，`QUIZ4..7`为四队页面，
  `QUIZ8`为比赛结束页。

## 迎新音乐管理

- 支持通过ffmpeg把常用音频转换为48kHz、16bit、单声道裸PCM；未安装
  ffmpeg时仅支持已经符合该规格的PCM WAV。
- 音乐区固定为物理LBA 300000起的38464个扇区，最长约205.1秒。
- 短于205.1秒的歌曲会在PC端循环铺满音乐区，避免播放完毕后出现长时间静音。
- 写入前同时解析FAT32/exFAT分配状态；目标簇已被文件占用时拒绝写入。
- 覆盖前备份完整音乐区，写入后清零剩余尾部并回读整区校验。
- 物理磁盘写入需要管理员权限。必须核对盘符、卷标和物理磁盘号，禁止选择系统盘。
- 写入音乐时建议直接双击 `以管理员身份启动素材管理器.bat`，避免物理磁盘访问被拒绝。
- 图片属于文件系统文件，而音乐位于裸扇区。应先完成全部图片更新，最后再写入音乐；
  后续再次修改图片后，应重新执行一次音乐安全写入和校验。

详细协议及字库范围见 `迎新流动通知串口使用说明.md`。
